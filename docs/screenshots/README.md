# Screenshots

Drop your UI captures here with these exact filenames so they render in the main
[`README.md`](../../README.md) and [`DEFENSE.md`](../../DEFENSE.md):

| Filename | What to capture |
|---|---|
| `ui.png` | The full app — sidebar + chat + composer |
| `chat-analysis.png` | A multi-image analysis answer (e.g. chest X-ray + brain MRI) |
| `report-pdf.png` | A report answer showing the **⬇ Download PDF** / **👁 Preview** buttons |
| `research.png` | A research answer with PubMed + Google Scholar links |
| `diagram.png` | A labelled Wikimedia anatomy diagram answer |
| `access-gate.png` | The restricted-content access-request gate |

PNG or JPG, ideally ~1200 px wide. The architecture/flow **diagrams** in the docs are
Mermaid and render automatically on GitHub — no files needed for those.
